# Simple Bank Management System

A C++ console application built to handle client records, account operations, and data management using file streams and standard library tools.

## 📌 Project Focus & Scope
* **Core Functionality Focus:** This project focuses primarily on core data manipulation, file processing logic, dynamic storage structures, and modular function design.
* **Storage Note:** This project uses a simple local text file (`Clients.txt`) for persistent data storage rather than a real SQL/relational database system.
* **Input Validation Note:** Basic input validation is intentionally kept minimal to focus purely on the core logic, memory management, and file operations.

## 🚀 Key Features
* **Client Record Management:** Create, search, update, and display client profiles.
* **Account & Banking Operations:** Perform core banking tasks such as balance checks, deposits, and transfers.
* **Data Persistence:** Automatically reads from and writes to a local text file (`Clients.txt`).
* **Console Interface:** Formatted terminal outputs and interactive menu navigation.

## 🛠️ Tech Stack & Concepts Applied
* **Language:** C++
* **IDE & Toolchain:** Microsoft Visual Studio (MSVC)
* **Key Libraries & Features:** File I/O (`<fstream>`, `<iomanip>`), dynamic containers (`std::vector`), string parsing, structs, and modular procedural functions.

## 💻 How to Run
1. Open `SimpleBankProject.sln` or `SimpleBankProject.vcxproj` in **Visual Studio**.
2. Press `Ctrl + F5` to build and run the application.
